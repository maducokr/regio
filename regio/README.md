# 레지오 마리아 활동 보고서 시스템

PostgreSQL을 사용하는 레지오 마리아 활동 보고서 저장 시스템입니다.

## 설치 및 실행 방법

### 1. PostgreSQL 데이터베이스 설정

PostgreSQL에서 데이터베이스를 생성합니다:

```sql
CREATE DATABASE regio;
```

### 2. 의존성 설치

```bash
npm install
```

### 3. 서버 실행

```bash
npm start
```

또는 개발 모드로 실행:

```bash
npm run dev
```

## 데이터베이스 정보

- **데이터베이스명**: regio
- **비밀번호**: 5854
- **테이블명**: legion_activity_reports

## 접속 방법

서버 실행 후 웹 브라우저에서 다음 주소로 접속:

```
http://localhost:3000
```

## 파일 구조
```
regio/
├── actinput.html      # 메인 입력 페이지
├── server.js          # Express 서버
├── package.json       # 프로젝트 설정
└── README.md         # 사용 설명서
```

## 기술 스택
- **Frontend**: HTML, CSS, JavaScript
- **Backend**: Node.js, Express
- **Database**: PostgreSQL
- **Dependencies**: pg, cors

## 주의사항
- PostgreSQL 서버가 실행 중이어야 합니다
- 데이터베이스 연결 정보는 server.js 파일에서 확인할 수 있습니다
- 모든 입력 필드는 필수 입력 사항입니다
